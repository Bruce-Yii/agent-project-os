# Security Policy

## Supported versions

This repository is pre-release and documentation-only. Security fixes apply
to the latest branch and documentation snapshot. No production release is
currently supported.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open
public issues for suspected vulnerabilities.

## Secrets

- Never commit real credentials, tokens, API keys, or private data.
- Use `.env.example` placeholders only.
- If a secret is accidentally committed, rotate it immediately and report
  the exposure privately.
